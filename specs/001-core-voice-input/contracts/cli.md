# CLI Contract: voice-type

**Feature**: 001-core-voice-input
**Date**: 2026-02-20

## Binary Name

`voice-type`

## Top-Level Structure

```
voice-type [OPTIONS] <COMMAND>

Options:
  -c, --config <PATH>    Config file path [default: ~/.config/voice-type.yaml]
  -v, --verbose          Increase logging verbosity (repeatable: -v, -vv, -vvv)
  -h, --help             Print help
  -V, --version          Print version

Commands:
  record     One-shot voice recording and transcription
  daemon     Start background daemon
  stop       Stop running daemon
  status     Show daemon status
  config     Configuration management
  help       Print help for a command
```

## Commands

### `voice-type record`

One-shot voice transcription (User Story 1). Opens a GTK window,
records audio, transcribes, displays result.

```
voice-type record [OPTIONS]

Options:
  -d, --device <NAME>      Audio input device (overrides config)
  -l, --language <CODE>    Language hint, ISO-639-1 (overrides config)
  -p, --prompt <TEXT>      Recognition prompt (overrides config)
  -h, --help               Print help
```

**Behavior**:
- Opens a recording window
- User starts/stops recording via UI
- Displays transcription result in window
- Exit code 0 on success, 1 on error

### `voice-type daemon`

Start background daemon (User Story 2). Listens for global hotkey,
manages overlay window lifecycle.

```
voice-type daemon [OPTIONS]

Options:
  -h, --help    Print help
```

**Behavior**:
- Uses `GtkApplication` with `IS_SERVICE` flag
- D-Bus single-instance enforcement (second invocation activates first)
- Listens for configured hotkey via evdev
- Shows overlay window on hotkey press
- Exit code 0 on clean shutdown, 1 on error

### `voice-type stop`

Stop running daemon.

```
voice-type stop [OPTIONS]

Options:
  -h, --help    Print help
```

**Behavior**:
- Sends quit signal to running daemon via D-Bus `activate`
- Exit code 0 if daemon stopped, 1 if daemon not running

### `voice-type status`

Show daemon status (FR-009).

```
voice-type status [OPTIONS]

Options:
  --json        Output as JSON
  -h, --help    Print help
```

**Output** (text mode):
```
Status: running
PID: 12345
Uptime: 2h 15m
Provider: openai (whisper-1)
Hotkey: Super+V
State: idle
```

**Output** (JSON mode):
```json
{
  "running": true,
  "pid": 12345,
  "uptime_seconds": 8100,
  "provider": "openai",
  "model": "whisper-1",
  "hotkey": "Super+V",
  "state": "idle"
}
```

**Behavior**:
- Queries daemon state via D-Bus
- Exit code 0 if daemon running, 1 if not running

### `voice-type config`

Configuration management subcommands.

```
voice-type config <COMMAND>

Commands:
  validate    Validate configuration file
  show        Show current effective configuration
  init        Create default configuration file
  docs        Print configuration documentation
```

#### `voice-type config validate`

Validate configuration file (FR-012).

```
voice-type config validate [OPTIONS]

Options:
  -h, --help    Print help
```

**Output** (valid):
```
Configuration is valid.
```

**Output** (invalid, SC-008 — all errors at once):
```
Configuration errors:
  - provider.api_key: missing required field
    Suggestion: Add `api_key: !FromEnv OPENAI_API_KEY`
  - audio.sample_rate: value 0 is out of range (8000..=48000)
    Suggestion: Use 16000 for optimal Whisper performance
  - hotkey.binding: "InvalidKey" is not a valid key combination
    Suggestion: Use format like "Super+V" or "Ctrl+Shift+R"
```

**Behavior**:
- Reports ALL validation errors in a single pass
- Each error includes field path, description, and suggestion
- Exit code 0 if valid, 1 if invalid

#### `voice-type config show`

Show effective configuration (resolved defaults, no secrets).

```
voice-type config show [OPTIONS]

Options:
  -h, --help    Print help
```

**Behavior**:
- Prints YAML with defaults filled in
- Secrets masked as `***`
- Exit code 0

#### `voice-type config init`

Create default configuration file (FR-008).

```
voice-type config init [OPTIONS]

Options:
  --force       Overwrite existing file
  -h, --help    Print help
```

**Behavior**:
- Creates `~/.config/voice-type.yaml` with documented defaults
- Refuses to overwrite without `--force`
- Exit code 0 on success, 1 if file exists (without --force)

#### `voice-type config docs`

Print configuration documentation (generated by `structdoc`).

```
voice-type config docs [OPTIONS]

Options:
  -h, --help    Print help
```

**Behavior**:
- Prints all configuration fields with types, defaults, descriptions
- Generated from `StructDoc` derive on config types
- Exit code 0

## Exit Codes

| Code | Meaning |
|------|---------|
| 0    | Success |
| 1    | General error (displayed to user) |
| 2    | Configuration error |

## Environment Variables

| Variable | Purpose |
|----------|---------|
| `OPENAI_API_KEY` | Default API key (via `!FromEnv` in config) |
| `XDG_SESSION_TYPE` | Detect X11 vs Wayland for text insertion |
| `VOICE_TYPE_CONFIG` | Alternative to `--config` flag |
| `VOICE_TYPE_LOG` | Log level override (e.g., `debug`, `trace`) |

## D-Bus Interface

**Bus name**: `com.voicetype.VoiceType`
**Object path**: `/com/voicetype/VoiceType`

The D-Bus interface is provided automatically by `GtkApplication`.
Used for:
- Single-instance enforcement (FR-011)
- `stop` command signaling
- `status` command querying
